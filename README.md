# ROS 2 bag to GSplatLoc

Turns one ZED 2i stereo recording (a ROS 2 bag) into a trained
[GSplatLoc](https://github.com/be2rlab/gsplatloc) map and localizes held-out images in it:
a 3D Gaussian splat whose Gaussians carry XFeat features, so a single camera image gives the
camera's position and heading.

```
bag ──bag2kitti──> stereo pairs (rectified) ──halve + check──> half resolution, corrupted frames found
    ──make_subsequence──> clean sequence (and legs, if SLAM must be split)
    ──pySLAM (Docker, headless)──> camera pose for every frame
    ──map2nerfstudio [+ merge_legs_one_spin]──> posed images ──stereo_densify──> dense starting cloud
    ──export_dataset_for_gsplatloc──> GSplatLoc input ──train.py + loc_inference (CUDA GPU)──> splat + poses
```

These settings reproduce the lab's reference result exactly (checked 2026-10-27: every file of
the GSplatLoc input regenerated byte for byte from the same SLAM maps). Change only what each step
says to change.

## What you need

| Where | What |
|---|---|
| Linux PC (no GPU needed) | Docker, [uv](https://docs.astral.sh/uv/), this repo, about 2 GB of disk per minute of recording for the images |
| CUDA GPU PC (reference: RTX 4090, 24 GB) | GSplatLoc, see "GSplatLoc setup" below |
| Camera | ZED 2i. `calibration/SN33088067.conf` is the factory calibration of the lab's camera (serial 33088067); another camera needs its own `SN<serial>.conf` from Stereolabs |

The pySLAM container mounts `~/ros2_bag`, so the data must live there:
```
~/ros2_bag/kitti/sequences/NN/   ~/ros2_bag/kitti/poses/   ~/ros2_bag/pyslam_cfg/   ~/ros2_bag/pyslam_out/   ~/ros2_bag/ns_data/
```

One-time setup on the PC:
```
cd ~/ros2_bag && uv venv --python 3.11 && uv pip install -r ~/qualcomm_evk_loc_demo/requirements_pipeline.txt
cd ~/qualcomm_evk_loc_demo && docker build -t pyslam_trimmed_headless -f pyslam_docker_image_trimmed_headless/Dockerfile .
```
The image build takes about 1.5 h and is CPU-specific (`-march=native`): build it on the machine that runs it.

All commands below run from `~/ros2_bag` with `P=~/qualcomm_evk_loc_demo/pipeline_bag_to_dataset`.
Sequence numbers are two digits and must be new in `kitti/sequences/`: `AA` the full recording,
`BB` its half-size copy, `CC` the clean sequence, `DD` and `EE` the two legs if SLAM must be split.

## 1. Bag to stereo pairs

```
uv run python $P/bag2kitti.py <bag folder> --list                  # check topic names
uv run python $P/bag2kitti.py <bag folder> kitti/sequences/AA \
    --left /zed_oc_sync/left/image_raw --right /zed_oc_sync/right/image_raw \
    --imu /zed_oc_sync/imu/data_raw --odom /odom --zed-conf ~/qualcomm_evk_loc_demo/calibration/SN33088067.conf
```
Rectifies with the factory calibration and pairs left and right frames within 2 ms. Check `log.txt`:
the sampled row error `|dy|` should be under about 1 px.

## 2. Half resolution and corrupted-frame check

```
uv run python $P/halve_sequence_and_check_frames.py kitti/sequences/AA kitti/sequences/BB
```
Writes the half-size images (1104x621 from 2K), `frame_quality.csv` (per frame: stereo row error,
stereo matches, sharpness) and `corrupted_frames.txt`. **Everything after this runs at half
resolution.** A 720p recording can skip this step; use AA wherever BB appears below.

## 3. Clean sequence, and legs if needed

```
uv run python $P/make_subsequence.py kitti/sequences/BB kitti/sequences/CC --drop kitti/sequences/BB/corrupted_frames.txt
```
**Split into legs** where SLAM cannot track, typically a spin in place that sweeps a blank wall.
Find it as a run of frames with very few `stereo_matches` in `frame_quality.csv` (the reference
recording dropped to a median of 7 over 270 frames) and cut it out:
```
uv run python $P/make_subsequence.py kitti/sequences/CC kitti/sequences/DD --first 0 --last <last frame before the gap>
uv run python $P/make_subsequence.py kitti/sequences/CC kitti/sequences/EE --first <first frame after the gap> --last <last frame>
```
If the recording has no such stretch, run SLAM on CC alone, skip step 7, and use CC wherever DD appears.

## 4. pySLAM configuration (for each sequence SLAM runs on)

```
T=~/qualcomm_evk_loc_demo/pyslam_patches_and_configs/pyslam_config_templates
uv run python $P/make_pyslam_settings.py kitti/sequences/DD/camera.txt kitti/sequences/DD/times.txt $T/ZED2i_HD.yaml pyslam_cfg/ZED2i_seqDD.yaml
cp $T/config.yaml pyslam_cfg/config_seqDD.yaml
```
Edit only these lines in `config_seqDD.yaml` (absolute paths, your own home folder):
```
KITTI_DATASET:
  base_path: /home/<you>/ros2_bag/kitti
  name: 'DD'
  settings: /home/<you>/ros2_bag/pyslam_cfg/ZED2i_seqDD.yaml
SYSTEM_STATE:
  folder_path: results/slam_state_DD
SAVE_TRAJECTORY:
  output_folder: /home/<you>/ros2_bag/pyslam_out/slam_state_DD/trajectory
```
The settings file gets the rectified intrinsics and fps from the sequence and keeps
`FeatureTrackerConfig.nFeatures: 2000`. Distortion stays 0, because the images are already rectified.

## 5. pySLAM

```
~/qualcomm_evk_loc_demo/pyslam_docker_image_trimmed_headless/run_pyslam_headless.sh pyslam_cfg/config_seqDD.yaml pyslam_out/slam_state_DD
TRAJ_DD=$(ls pyslam_out/slam_state_DD/trajectory_*/trajectory_final.txt | tail -1)
```
Stereo ORB SLAM: ORB2 features, 2000 per frame, 8 levels, scale 1.2, ratio test 0.7, DBoW3 loop
closure. pySLAM is pinned at commit a5ff256, with the two patches in `pyslam_patches_and_configs/`
built in. The run finishes by itself with bundle adjustment, `slam_state/map.json` and
`trajectory_<timestamp>/trajectory_final.txt`. It takes about 6 min per 4,800 frames, and both legs
can run at the same time.

**Check every run before using it.** pySLAM is not deterministic, and a bad run gives a bad map:
- `headless.log` contains `HEADLESS: MAP SAVED`.
- `grep -a -c "state: LOST\|Relocalizing" pyslam_out/slam_state_DD/headless.log` is 0. If it isn't,
  find where it happened: a recovery after a loss can attach the rest of the run in the wrong place.
- Step 6 prints the SLAM/odometry distance ratio. It should be about the same for every run with
  the same robot (reference 1.12; wheel odometry under-reports at low speed). A run that disagrees
  with the others is suspect.

If a run fails a check, run it again. The reference sequence failed in 1 of 4 reruns.

## 6. Posed images, one dataset per SLAM run

```
uv run python $P/map2nerfstudio.py --map pyslam_out/slam_state_DD/slam_state/map.json --seq kitti/sequences/DD \
    --out ns_data/seqDD --use-right --drop-blurriest 0.2 --odom kitti/sequences/DD/odom.csv --traj $TRAJ_DD
```
This takes the keyframes plus one tracked frame every 5 cm or 5 deg, drops the blurriest 20% of
keyframes, and removes glitch poses.

## 7. Merge the legs (only if step 3 split the recording)

```
uv run python $P/merge_legs_one_spin.py --a ns_data/seqDD --a-traj $TRAJ_DD --b ns_data/seqEE --b-traj $TRAJ_EE \
    --b-offset <EE's --first from step 3> --seq kitti/sequences/CC --out ns_data/seqCC_merged
```
This joins two legs separated by one spin in place. The spin centre ties the legs together, the
gyro gives the heading across the gap, and the two legs' stereo clouds refine it. Check the
printed agreement of the two clouds (reference: median 4 to 6 cm). For legs separated by two
spins, use `merge_legs.py` instead.

## 8. Dense starting cloud

```
uv run python $P/stereo_densify.py --data ns_data/seqCC_merged --seq kitti/sequences/CC --max-depth 6 --voxel 0.02 --scale 1.0
```
SGBM stereo depth on every frame, back-projected with the SLAM poses. **`--scale 1.0` is not the
default.** Without a merge, use `--data ns_data/seqDD --seq kitti/sequences/DD`.

## 9. GSplatLoc input

```
uv run python ~/qualcomm_evk_loc_demo/gsplatloc_on_4090/export_dataset_for_gsplatloc.py \
    --data ns_data/seqCC_merged --out gsplatloc_data/<name> --scale 1.0
scp -r gsplatloc_data/<name> <gpu pc>:gsplatloc/data/
```
This writes left images only, cropped so the principal point is exactly at the image centre
(GSplatLoc assumes it), plus a COLMAP text model and 400,000 starting points. Every 8th image is
held out as a test image. Use `--scale 0.5` if the images are still 2K.

## 10. GSplatLoc (CUDA GPU)

```
cd ~/gsplatloc && source .venv/bin/activate
N=<name>
python train.py -s data/$N -m output/$N --eval --iterations 11900 \
    --save_iterations 8900 11900 --test_iterations 3000 6000 8900 11900 --data_device cpu 2>&1 | tee output_$N.log
python loc_inference_with_dump.py -m output/$N 2>&1 | tee loc_$N.log
```
- **`--iterations` must be given.** The code's default is 2,000, although its README says 30,000.
  11,900 stops just before an opacity reset (one every 3,000 steps).
- `--eval` creates the held-out test set. Without it nothing is localized.
- Outputs:
  - `output/$N/point_cloud/iteration_11900/point_cloud.ply`: the splat (SuperSplat opens it);
  - `output/$N/error_logs/`: median errors, recall at 10 cm/5 deg and so on, and per-query poses;
  - `output/$N/loc_examples/`: each query beside a render at the estimated pose.
- Reference run: 1,195 images, 29 min on an RTX 4090, test PSNR 28.6, median error 8.2 cm / 0.28 deg after refinement.
- `Loss=nan` in the progress bar is normal for this code.

### GSplatLoc setup (once)

```
git clone https://github.com/be2rlab/gsplatloc.git ~/gsplatloc && cd ~/gsplatloc && git checkout a6bdba0
git apply ~/qualcomm_evk_loc_demo/gsplatloc_on_4090/gsplatloc_a6bdba0_local_changes.patch
cp ~/qualcomm_evk_loc_demo/gsplatloc_on_4090/loc_inference_with_dump.py .
uv venv --python 3.10 .venv && source .venv/bin/activate      # needs Python.h: sudo apt install python3.10-dev
uv pip install pip setuptools wheel
cat >> .venv/bin/activate <<'EOF'
export CUDA_HOME=/usr/local/cuda-12.6
export PATH=$CUDA_HOME/bin:$PATH
export LD_LIBRARY_PATH=$CUDA_HOME/lib64:$LD_LIBRARY_PATH
EOF
source .venv/bin/activate && nvcc --version                   # must match the CUDA version of the torch build
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126
pip install -r requirements.txt
pip install --no-build-isolation submodules/diff-gaussian-rasterization submodules/simple-knn
python -c "import torch, diff_gaussian_rasterization, simple_knn; print(torch.__version__, torch.cuda.is_available())"
```
The patch does two things:
- sets `debug = False` in `arguments/__init__.py`. The default `True` cannot be turned off from the
  command line, and it halves training speed.
- adds the `#include`s that gcc 13 needs.

Reference environment: torch 2.14.1+cu126, numpy 2.2.6, CUDA 12.6, gcc 13.3.

`loc_inference_with_dump.py` is GSplatLoc's `loc_inference.py` plus per-query results and example
pictures. Where the original crashes on a failed PnP, it handles the failure instead.

## Recording advice (what breaks SLAM)

- Turn by stopping and spinning in place, never while driving. Never end a turn facing a blank wall.
- Cover each corridor in both directions: a direction the map has not seen cannot be localized.
- Record at 720p and 15 fps, or check the frame drops: 2K dropped about half the frames.
- Drive slowly: about 0.05 m/s gave sharp images, 0.3 m/s blurry ones.
- Record `/odom` and the ZED IMU. Drop topics you don't need.
